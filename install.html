WordPress plugin

Install Elementiq on your WordPress site.

Elementiq runs inside WordPress. Upload the plugin ZIP, activate it, then open Elementiq from the dashboard. You do not need to export or move a site into WordPress.

Start building Need help?

Install from a ZIP file

This is the path for a normal WordPress user. You need an administrator account on the site where you want Elementiq.

01

Log in to WordPress

Open your site and go to the login screen. Sign in with an administrator account.

02

Open the dashboard

After login you should see the WordPress admin. Look at the left-hand menu.

03

Go to Plugins

Click Plugins, then choose Add New Plugin.

04

Upload the ZIP

Choose Upload Plugin. Select the Elementiq ZIP file, then click Install Now.

05

Activate Elementiq

When the install finishes, click Activate Plugin. Elementiq appears in the WordPress admin menu.

After activation

Where to find Elementiq

Look for Elementiq in the left admin menu. Open Pages to create or edit a builder page. Settings is where you connect an AI provider later.

What to do next

Create a page, open it in Elementiq, and choose Design or Studio. Follow Getting started if this is your first time.
