Questions

Straightforward answers about Elementiq.

Elementiq is a WordPress plugin with two editors. Design is visual drag and drop. Studio is AI assisted coding with a live preview. Pages save on your WordPress site.

What is Elementiq?

Elementiq is a powerful WordPress website builder that combines visual drag and drop design with AI assisted coding. You install it as a plugin and use it from the WordPress dashboard.

Is Elementiq a WordPress plugin?

Yes. It runs inside WordPress. It is not a separate hosting platform, and you do not export a site into WordPress to use it.

Where do I install Elementiq?

Log in to WordPress, open Plugins → Add New Plugin, upload the Elementiq ZIP, install, then activate. After that, Elementiq appears in the admin menu. See the install guide for each step.

What is the difference between Design and Studio?

Design is the main visual drag and drop editor. You add widgets, create layouts, and style the canvas. Studio is the AI coding workspace. You describe what you want, and Studio can create or edit HTML, CSS, and JavaScript. You can also edit the live preview in Studio.

Do I need coding knowledge to use Design?

No. Design is built for visual editing. You drag widgets, edit content, and use the inspector for colors, spacing, typography, and images.

Can Studio write HTML, CSS, and JavaScript?

Yes. That is what Studio is for. Ask in natural language, then review the live preview and the files in Explorer.

How does AI work in Elementiq?

AI is used in Studio. You connect a provider, send a request, and Studio applies code to the page. Design can still be used without AI. Results depend on the provider and the key you configured.

Where do I configure my AI provider?

Open Elementiq → Settings in the WordPress dashboard. Choose a provider, add an API key, and test it. Providers and models are not free unless that provider says so.

Can I edit the AI generated design visually?

Yes, in Studio. Click the live preview to change text, colors, sizes, images, and other supported properties. If you want widget drag and drop instead, switch to Design.

Where are my pages saved?

On your WordPress site. Create and open pages from Elementiq → Pages. When you publish, visitors use a normal WordPress permalink.

Does Elementiq work inside WordPress?

Yes. Install the plugin, activate it, and build from the dashboard. There is no transfer step into WordPress.

Does Elementiq work with WooCommerce?

Yes. Elementiq designs the shop. WooCommerce runs products, cart, checkout, and orders. If you ask Studio or Design to create a store, the AI is instructed to use WooCommerce widgets and shortcodes, not fake product cards. See the WooCommerce partnership page.

What should I do if the editor does not load?

Hard refresh the browser, confirm you opened the page from Elementiq → Pages, and check that the plugin is still active. The help page has more troubleshooting steps.
