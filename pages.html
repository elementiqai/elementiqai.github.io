Inside WordPress

Pages is where you start building.

After you activate Elementiq, open Elementiq → Pages in the WordPress dashboard. Create a page, open it in Design or Studio, then save. These are real WordPress pages with normal permalinks.

Start building Install Elementiq
Desktop. Pages

Create a page, open the builder, and manage your Elementiq pages.

What you can do here

Create a page

Type a title and create the page. Elementiq opens the builder on a WordPress page, not a copy stored somewhere else.

Open Design or Studio

Open in builder, then choose Design for drag and drop or Studio for AI assisted coding.

View and publish

View the front of the site. Status stays WordPress: draft until you publish. Visitors use the permalink.

Header and footer shortcuts

Theme builder cards sit next to the list so you can design site-wide header and footer parts without leaving Pages.

Generate on an empty page

If the canvas is empty and AI is configured, you can ask Studio to create the first layout from a short brief.
