Studio

AI assisted coding. Live preview.

Studio is the coding workspace in Elementiq. Describe what you want in natural language. Studio can create or modify real HTML, CSS, and JavaScript. Then click the live preview to refine text, colors, sizes, and images. Studio is not a second copy of Design.

What you can ask Studio to do

Talk to Studio the way you would brief a developer. Be specific about layout, copy, brand colors, and interactions.

HTML

Create sections, headings, lists, forms, and page structure. Ask to add a new block or rewrite an existing one.

CSS

Change colors, spacing, typography, and layout. Ask for a tighter hero, a wider grid, or a darker footer.

JavaScript

Add simple interactions when the page needs them, such as toggles, tabs, or form behavior.

Layouts

Describe a landing page, a services grid, or a two-column about section. Studio builds the structure in code.

Components

Ask for reusable pieces such as cards, testimonials, pricing rows, or a contact strip.

Styling and motion

Request hover states, spacing systems, or other visual polish that belongs in CSS and JavaScript.

How Studio is laid out

A

Chat

Type a request, attach a file when you have a brief or logo, then send. Studio replies with the change it made to the page.

P

Live preview

See the rendered page immediately. Click an element to edit visual properties without writing a new prompt for every small change.

E

Explorer

Open the HTML, CSS, and JavaScript files for the page. This is the real code Studio writes, not a mockup.

If a result is not right, ask Studio to try again or restore a backup. The WordPress page stays until you save.

Before you generate

Connect an AI provider

Studio needs a provider and API key in Elementiq → Settings. Design still works without one. See AI setup for the exact steps.

Know the difference

Design uses widgets on a canvas. Studio writes code and shows a live preview. Use the tab switch to move between them on the same WordPress page.
