New

Switch pages from the editor header

The page name at the top of the editor is now a button. Jump to any other page without going back to the WordPress dashboard.

  1. Click the page nameIn Vibe coding it sits next to the Design / Vibe coding switch. In Design it is at the top of the left panel.
  2. Find the pageScroll the list or type in Search pages. Each page shows whether it is published or a draft. Press Enter to open the first match.
  3. Click it to openIf you have unsaved changes, Elementiq saves them first, then opens the new page in the same editor.
  4. Need a new page?Type a title in New page title and press Add. The page is created and opened straight away.

New

Delete a section from the preview

Remove a whole part of a Vibe coding page, such as a banner or a block you no longer want, right from the live preview. No prompt needed.

  1. Open the page in Vibe codingMake sure the Preview tab is selected above the page.
  2. Hover the sectionA pink outline marks the section, and a small bar appears with + Add section and Delete.
  3. Click Delete twiceThe first click changes the button to Click again to delete. Click again within three seconds to remove it. This stops accidental deletes.
  4. Changed your mind?Open Backups in the top bar to bring back an earlier version of the page.

New

Add a new section with AI

Ask Elementiq’s AI for one new section, and it writes it in the same style as the rest of your page. Everything else on the page stays as it is.

  1. Choose where it goesHover the section that should come before the new one, then click + Add section or the round + button at its bottom edge.
  2. Describe the sectionA small chat opens. Tap an idea such as Testimonials, FAQ, or Pricing plans, or type your own, for example “Three customer reviews with star ratings”.
  3. Send and wait a momentThe chat shows Writing your section…. When it is done, the chat closes and the preview scrolls to the new section.
  4. Fine-tune itClick any text or image in the new section to change it, just like the rest of the page.

This uses the AI provider you connected in Elementiq → Settings. If the provider is busy, the chat shows the error and nothing on your page changes. AI setup

Improved

See the image before you replace it

When you click a photo, the side panel now shows the current image instead of a plain button, so you always know what you are changing.

  1. Click a photo in the previewThe Explorer panel on the right switches to Edit for that image.
  2. Click the image previewHover it to see Replace, then click. The WordPress Media Library opens on top of the editor.
  3. Upload or pick a fileChoose an image and confirm. The preview and the panel update right away.
  4. Finish the detailsWrite Alt text for search engines and screen readers, use Smaller / Larger, and pick rounded Corners if you like.

New

Vibe coding pages now show up in Design

If you built a page in Vibe coding and then open the Design tab, you see your real page instead of an empty canvas. You can change its words right there.

  1. Switch to DesignA banner explains that the page was built with Vibe coding.
  2. Click any heading or paragraphIt gets an outline and you can type. Click outside it when you are done. Save or Update as usual.
  3. Clicked a photo or a layout area?The banner tells you to change it in Vibe coding instead, so nothing breaks.
  4. Go to Vibe codingPress Edit in Vibe coding in the banner to change images, colors, layout, or sections.

New

Clone a website into WordPress

Bring an existing website into your WordPress site. Every page becomes a page you can keep editing in Vibe coding.

  1. Open Elementiq → Clone WebsitePick how to bring the site in: Upload ZIP / HTML, Upload folder, or Clone URL.
  2. Using Clone URL?Type the website address, choose how many pages to copy, and tick I own this website or have permission to copy it.
  3. Set the optionsGive it a name, choose Save as drafts or Publish, and decide if Elementiq should create a navigation menu or make the cloned home page your front page.
  4. Press Clone websiteThe new pages appear under Cloned websites. Use Open to edit them or Undo to remove the whole import.

Only clone websites you own or have permission to copy. Sites that build their content with JavaScript in the browser may come out mostly empty.

New

Collect form messages and get email alerts

Build a contact form, place it on any page, and read every message in one inbox inside WordPress.

  1. Open Elementiq → FormsPress Create form and build it with drag and drop, or add a Form widget to a page in Design. Both send into the same inbox.
  2. Place the formCopy the form’s shortcode, such as [aiwb_form id="1"], and paste it where the form should appear.
  3. Read messagesOpen the Activity tab to see every submission. Messages are saved there even when email is off.
  4. Turn on email alertsOpen SMTP, enter your mail server details, save, and press Send test email to check it works.
