First time

From install to your first published page.

Follow this path if you have never used Elementiq. You will install the plugin, open WordPress, create a page, choose Design or Studio, then save.

Install Elementiq Design vs Studio

Your first workflow

01

Install Elementiq

Upload the ZIP in Plugins → Add New, then activate. See the install guide if you need each click.

02

Open WordPress

Sign in to the dashboard. Elementiq should appear in the left menu after activation.

03

Create a page

Go to Elementiq → Pages. Type a title such as Home, then create and open the page in the builder.

04

Choose Design or Studio

Use Design to drag widgets. Use Studio to describe the page and let AI write HTML, CSS, and JavaScript.

05

Build, preview, save

Check the result, then save. Visitors see the page on your WordPress site when you publish.

Which editor should you open first?

Start in Design

Best if you want to add a heading, image, and button yourself. Open the Elements panel, drag widgets onto the canvas, then style them in the inspector.

Open Design

Start in Studio

Best if you want to describe the whole page. Connect an AI provider first, then send a short brief. Refine the live preview, then save.

Open Studio

Before you use AI

Design does not require an API key. Studio does. Open Elementiq → Settings, add a provider, and test the key. Capabilities depend on that provider. Keys are not free unless the provider offers a free plan.
