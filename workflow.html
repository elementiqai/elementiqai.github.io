Design vs Studio

Two editors. One WordPress page.

Use Design to build visually with drag and drop widgets and layouts. Use Studio for AI assisted coding, custom HTML, CSS, JavaScript, and live preview edits. Save either way on your WordPress site.

Design

Best for building visually with drag and drop widgets and layouts. Open the canvas, add elements, edit content, and style with the inspector. No API key required.

Open Design

Studio

Best for AI assisted coding, custom HTML, CSS, JavaScript, and advanced customization. Describe the page, review the live preview, then save. Needs an AI provider.

Open Studio

01. Design

See it. Move it. Style it.

Search widgets, drop them on the canvas, and arrange sections and columns. Double click text. Replace images. Check desktop, tablet, and mobile before you save.

Desktop. Design

Widget library, canvas, and inspector.

Desktop. Studio

Chat, live preview, and page files.

02. Studio

Describe it. Refine the preview.

Send a brief. Studio writes real HTML, CSS, and JavaScript. Click the preview to change words, color, size, and images. Restore a backup if a turn goes the wrong way.

03. Save in WordPress

Publish on the same site you already have.

Save, then Update or Publish. The permalink is a WordPress URL. Header, footer, SEO, and media stay with the page. You never export the site into WordPress.
