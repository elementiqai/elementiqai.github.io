Studio capability

Edit the live preview. Keep the code.

After Studio generates a page, you can click the rendered website and make visual changes where the preview supports them. This is the bridge between AI generated code and hands-on editing. It is not the Design widget canvas.

Open Studio Start building
Desktop. Studio preview

The preview shows the real page. Click an element to change visual properties.

What you can change on the preview

Select an element on the live page. Controls appear so you can refine the result without writing a new prompt for every small tweak.

Change text

Click a heading or paragraph and rewrite the words. Useful after AI drafts copy that needs your brand voice.

Change colors

Adjust text and background colors so the generated design matches your palette.

Adjust sizes

Make type larger, tighten spacing, or resize an element so the layout feels balanced.

Replace images

Swap a generated or placeholder image for one from your media library.

Edit visual properties

Change other supported properties on the selected element, then check the preview again.

Save in WordPress

When the preview looks right, save. The page stays on your WordPress site, not on a separate host.

Where this fits

After AI writes the page

Ask Studio to create a layout. Then use the preview to correct copy, color, and images without starting over.

When you want widgets instead

Switch to Design. Design is drag and drop with widgets. Live preview editing belongs to Studio.
