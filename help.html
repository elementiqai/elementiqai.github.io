Documentation

Guides for building, saving, and fixing issues.

Use this page as the help hub. Start with the task you need, then open the matching guide. Elementiq is a WordPress plugin with two editors: Design for drag and drop, Studio for AI assisted coding.

Learn by task

Getting started

Install, open WordPress, create a page, choose Design or Studio, preview, and save.

Installation

Upload the ZIP from Plugins → Add New, activate Elementiq, and find it in the admin menu.

Using Design

Drag widgets onto the canvas, style them in the inspector, then preview desktop, tablet, and mobile.

Using Studio

Describe the page. Studio writes HTML, CSS, and JavaScript. Refine the live preview next.

AI setup

Open Settings, connect a provider, paste an API key, and test it before generating.

Live preview

Click the rendered page in Studio to change text, colors, sizes, and images.

Saving changes

Use Save to keep work on the current page. Use Update or Publish when you want WordPress to show the page to visitors. Pages live on your WordPress site. They are not exported to another platform.

If nothing appears on the front

Confirm the page is published, not still a draft. Open Pages, choose View, and check the permalink.

If the editor looks empty after a save

Reload the page in Elementiq. If it still fails, see troubleshooting below.

Troubleshooting

Try these steps first. They cover the problems people hit most often after a new install.

Elementiq does not appear after activation

Confirm the plugin is listed as Active under Plugins. Refresh the dashboard. Look for Elementiq in the left menu. If it is missing, deactivate and activate once more. You need an administrator account.

The editor does not load

Hard refresh the browser (Ctrl+F5). Try another browser, or disable a conflicting admin plugin briefly. Confirm you opened the page from Elementiq → Pages rather than a random admin URL.

Studio cannot generate code

Open Settings and confirm a provider is selected. Send a shorter request. If the provider is down, wait and try again. The page you already built stays in WordPress.

The AI provider is not connected

Go to Elementiq → Settings. Choose a provider, paste a key, and use the test action if it is available. Design still works without a key.

The API key is invalid

Copy the key again from the provider dashboard. Remove extra spaces. Confirm the key belongs to the provider you selected in Settings. Billing or quota issues on the provider side can also look like an invalid key.

The live preview does not update

Wait for Studio to finish applying files. Click Preview again in Explorer. If the preview is stale, save, reload the builder, then reopen Studio.

Changes are not being saved

Click Save, then confirm WordPress did not show an error. Check that you are still logged in. If Update fails, try saving as a draft first, then publish from Pages.
