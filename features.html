What you can do

Visual building and AI coding, in WordPress.

Elementiq is a powerful WordPress website builder that combines visual drag and drop design with AI assisted coding. Design is the visual editor. Studio is the AI coding workspace. Both save pages on your WordPress site.

Open Design Open Studio

Design. Visual building.

Use Design when you want to add widgets, move them on the canvas, and style the page yourself. You do not need to write code.

Drag and drop

Choose a widget from the Elements panel and drop it onto the canvas. Rearrange sections, columns, and content until the layout feels right.

Widgets

Headings, text, buttons, images, videos, forms, tabs, and more. Search the library instead of scrolling a long list.

Layouts

Start with sections, containers, columns, and grids so the page has a clear structure before you add content.

Visual styling

Change colors, spacing, typography, borders, and backgrounds in the inspector. What you see on the canvas is what visitors get after you save.

Responsive editing

Switch between desktop, tablet, and mobile widths so you can check how the layout behaves on smaller screens.

Page building

Open any WordPress page from Elementiq → Pages, build it in Design, then save. The page stays on your site.

Studio pages in Design

A page built in Studio shows up in Design as the real page, not a blank canvas. Click any text to change the words.

Page switcher

Click the page name at the top of the editor to search your pages and jump to another one, or add a new page.
See the widget library

Studio. AI assisted coding.

Use Studio when you want to describe the page in natural language and let AI write or change real website code.

Natural language

Type what you want: a hero, a pricing table, a contact form, a new color, or a layout change. Studio turns that request into code.

HTML generation

Studio can create and edit the page structure in HTML. You can inspect the files in Explorer after a change.

CSS customization

Ask for spacing, colors, fonts, or layout tweaks. Studio writes CSS so the preview matches what you described.

JavaScript customization

Ask for interactions such as tabs, sliders, or simple page behavior. Studio can add JavaScript when the request needs it.

Live preview editing

Click the rendered page to change text, colors, sizes, and images. This is the bridge between generated code and visual edits.

AI configuration

Studio needs a connected provider and API key in Settings. Available models and results depend on the provider you choose.

Delete sections

Hover a section in the live preview and click Delete twice to remove it. Backups bring it back if you need it.

Add a section with AI

Press + under any section, describe what you want, and AI writes one new section in the same style as your page.

Image replace

Click a photo to see it in the side panel, then replace it from the WordPress Media Library and add alt text.
How live preview works

WordPress integration

Elementiq is a plugin. You install it, activate it, and use it from the WordPress dashboard. You do not export a site into WordPress.

WooCommerce

Ask for a store. Design and Studio use live Woo products, cart, and checkout instead of fake shop cards.

Pages

Create a WordPress page, open it in Elementiq, and choose Design or Studio. View and publish from the same list.

Clone Website

Bring in a site you own from a ZIP, a folder, or a web address. Every page becomes a Studio page you can edit.

Forms and SMTP

Build contact forms, read every message in Activity, and send email alerts through your own mail server.

Reusable site parts

Build a header and footer once, then assign them across pages so the site looks consistent.

Settings

Connect an AI provider, choose a layout template, and keep keys on your WordPress install.

SEO

Titles, descriptions, social cards, and a content score live with each page so search appearance is not a separate chore.

Cybersecurity

Scan files, harden common WordPress surfaces, and review activity from the Elementiq menu.

File Manager

Browse hosting files from Elementiq when you need to upload, rename, or preview files on the server.
