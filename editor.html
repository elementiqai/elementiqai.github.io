Design

The visual drag and drop editor.

Design is the main visual editor in Elementiq. Add widgets, create layouts, move elements on the canvas, edit content, and style the page without writing code. When you are ready, save the page in WordPress.

How to build in Design

This is the everyday path for a new page. You stay inside WordPress the whole time.

01

Open a page

In WordPress, go to Elementiq → Pages. Create a page or open an existing one.

02

Launch Design

Open the page in Elementiq and choose Design. You will see the widget library, canvas, and inspector.

03

Add widgets

Search or browse Elements. Drag headings, text, images, buttons, and layout blocks onto the canvas.

04

Arrange the layout

Use sections, containers, and columns to structure the page. Move widgets until the hierarchy is clear.

05

Style and preview

Select an element and change content or style. Check desktop, tablet, and mobile, then save.

What you can customize

Select anything on the canvas. The inspector shows the controls that apply to that widget.

Text and content

Edit headings, paragraphs, button labels, and other copy. Double click text on the canvas to change it in place.

Colors

Set text, background, border, and accent colors so the page matches your brand.

Typography

Adjust font size, weight, line height, and alignment so the page is easy to read.

Spacing

Control padding, margin, and gaps between columns so the layout can breathe.

Images

Replace images from the WordPress media library. Add alt text so the page stays accessible.

Buttons and links

Change labels, colors, and destinations. Link to other pages on your WordPress site or to an external URL.

Design is not Studio

Use Design when

You want to build visually. You prefer widgets, drag and drop, and seeing every change on the canvas as you make it.

Switch to Studio when

You want AI to write HTML, CSS, and JavaScript from a description, then refine the result on the live preview.
